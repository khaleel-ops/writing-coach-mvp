# Writing Coach MVP

Paste three emails you sent this week. Get a one-page diagnostic: two writing patterns (with quoted lines from your emails) and a five-minute drill.

## Local development

```bash
cp .env.example .env
# Add your Anthropic API key to .env
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
